# H2برو — النظام المحاسبي الشامل

مشروع تطبيق Android محاسبي شامل باللغة العربية.

## حالة المشروع

المشروع قيد التطوير، ويحتوي حالياً على وحدات للواجهة الرئيسية، قاعدة البيانات المحاسبية، الأستاذ العام، المخزون، المشتريات، المرتجعات، الفواتير والتقارير المالية.

## الهدف

بناء نظام محاسبي عملي وسهل الاستخدام للشركات والمنشآت، مع التركيز على سلامة القيود والحسابات والتقارير.
